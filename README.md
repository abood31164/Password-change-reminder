# Password Change Reminder

تطبيق جوّال لتذكيرك بتغيير كلمات مرور حساباتك بشكل دوري. يدعم العربية والإنجليزية، الإشعارات المحلية، القفل بالبصمة أو Face ID، ومولّد كلمات مرور قوية.

## الخصوصية

يتم حفظ أسماء الخدمات ومواعيد التذكير محليًا على الجهاز. التطبيق لا يحفظ كلمات المرور ولا يرسل بيانات الحسابات إلى خادم.

## تشغيل المشروع

يتطلب Node.js و pnpm و Expo.

git clone https://github.com/abood31164/Password-change-reminder.git
cd Password-change-reminder
pnpm install
pnpm start

بعدها افتح المشروع عبر Expo Go أو المحاكي.

ملاحظة: GitHub يوفر كود المشروع، وليس ملف تثبيت Android أو iOS جاهزًا في الوقت الحالي.
